二叉树：高度、排序与平衡判断

空树高度为 0，叶子高度为 1；排序树采用严格递增定义。以下为考研 C 语言基础模板。

typedef struct BiTNode {
    int data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;

01 · 求树高：后序三行

左、右、根：左右子树高度最大值加 1。

int Height(BiTree T)
{
    if (T == NULL) return 0;
    int L = Height(T->lchild), R = Height(T->rchild);
    return (L > R ? L : R) + 1;
}

向下调用 A → B → D → F；F 的两个空孩子返回 0，之后逐层返回，处理其他子树。

02 · 判断二叉排序树：中序 + pre + flag

中序遍历严格递增，当且仅当该树为二叉排序树。 pre 记录上一次访问结点，flag 记录是否曾出现逆序。保留普通中序遍历结构。

BiTNode *pre = NULL;
int flag = 1;

void InOrder(BiTree p)
{
    if (p == NULL) return;
    InOrder(p->lchild);
    if (pre != NULL && pre->data >= p->data)
        flag = 0;
    pre = p;
    InOrder(p->rchild);
}

// 每次判断前重置全局变量
int IsBST(BiTree T)
{
    pre = NULL;
    flag = 1;
    InOrder(T);
    return flag;
}

中序序列：5 → 3 → 9 → 10。

pre（比较前）pflag（比较后）操作
NULL51跳过比较，pre = p
5305 ≥ 3，flag = 0；pre = p
390比较通过，pre = p
9100比较通过，pre = p

最终 flag = 0；若全部比较严格递增则返回 1。

仅写 return; 只会结束当前递归栈帧。例如结点 3 返回后，结点 9 仍继续执行；必须使用共享 flag 或逐层传递返回值。flag 一旦为 0 不再改回 1。

需要提前结束时

// 替换 InOrder，IsBST 的初始化不变
void InOrder(BiTree p)
{
    if (p == NULL || flag == 0) return;
    InOrder(p->lchild);
    if (flag == 0) return;
    if (pre != NULL && pre->data >= p->data) {
        flag = 0;
        return;
    }
    pre = p;
    InOrder(p->rchild);
}

时间 O(n)，递归栈 O(h)。

03 · 判断平衡二叉树：无 height 属性

任意结点左右子树高度差绝对值不超过 1。 直接复用第 01 节 Height。外层先序判断，内层后序求高；每个结点重新计算其左右子树高度。

int IsBalance(BiTree T)
{
    if (T == NULL) return 1;
    int L = Height(T->lchild);
    int R = Height(T->rchild);
    if (L - R > 1 || R - L > 1) return 0;
    if (IsBalance(T->lchild) == 0) return 0;
    if (IsBalance(T->rchild) == 0) return 0;
    return 1;
}
步骤当前结点内部 Height 返回顺序（非空结点）L / R结果
1AF → D → B；E → C3 / 2通过，递归左子树
2BF → D2 / 0失败，返回 0
3A无—接收到 0，返回 0，不检查 C

根 A 平衡不代表整棵树平衡。对下方平衡树，A 检查时求高顺序 D → E → B → C；B 检查时再次求 D、E。判断顺序 A → B → D → E → C。

时间上界 O(n²)，递归栈 O(h)。

04 · 判断平衡二叉树：有 height 属性

先统一后序计算并保存所有子树高度，再独立先序判断，不重复计算。以下结点定义与第 01 节互为替代，不要同时定义。

typedef struct BiTNode {
    int data;
    int height;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;

int Height(BiTree T)
{
    if (T == NULL) return 0;
    int L = Height(T->lchild), R = Height(T->rchild);
    T->height = (L > R ? L : R) + 1;
    return T->height;
}

int IsBalance(BiTree T)
{
    if (T == NULL) return 1;
    int L = 0, R = 0;
    if (T->lchild != NULL) L = T->lchild->height;
    if (T->rchild != NULL) R = T->rchild->height;
    if (L - R > 1 || R - L > 1) return 0;
    if (IsBalance(T->lchild) == 0) return 0;
    if (IsBalance(T->rchild) == 0) return 0;
    return 1;
}

// 调用顺序（在调用函数中执行）
Height(T);
int flag = IsBalance(T);
