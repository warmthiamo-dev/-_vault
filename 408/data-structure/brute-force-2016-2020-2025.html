2016 年 43 题 · 集合划分

将 n 个正整数划分成两个不相交且覆盖全集的集合，使元素个数差最小、元素和差最大。

原始思路

快速排序得到升序序列，前 n/2 个元素求和 S1，剩下元素求和 S2，返回 S2-S1。奇数时多出的元素放在较大集合；正数条件保证这样不会缩小最大差。固定较小集合大小时，选最小的元素使其和最小。

手工推演

S1=6，S2=29，个数差=1，和差=23。

int PartitionSet(int A[], int n) {
    QuickSort(A, 0, n-1); // 使用下方快速排序
    int S1=0, S2=0;
    for(int i=0;i<n/2;i++) S1+=A[i];
    for(int i=n/2;i<n;i++) S2+=A[i];
    return S2-S1;
}

平均时间 O(n log n)，平均辅助空间 O(log n)；最坏时间 O(n²)，最坏递归空间 O(n)。也可以用冒泡排序替代，时间 O(n²)，空间 O(1)。

主动提出的优化：基准值找得好，一次划分就够

不要求集合内部有序，只要求分界位置 k=n/2 正确。单趟划分返回基准值下标 p，若 p=k 即结束，否则仅处理含 k 的一侧。

1327589

例如第一次基准值为 8，划分结果可为 [1,3,5,2,7,8,9]，p=5，只处理下标 0~4；下一次选 5，结果可为 [1,3,2,5,7,8,9]，p=3，结束。以上为满足划分性质的示意序列，不限定具体交换轨迹。

int Partition(int A[], int low, int high) {
    int pivot=A[low];
    while(low<high){
        while(low<high && A[high]>=pivot) high--;
        A[low]=A[high];
        while(low<high && A[low]<=pivot) low++;
        A[high]=A[low];
    }
    A[low]=pivot;
    return low;
}
void QuickSort(int A[],int low,int high){
    if(low<high){
        int p=Partition(A,low,high);
        QuickSort(A,low,p-1);
        QuickSort(A,p+1,high);
    }
}
void QuickSelect(int A[],int low,int high,int k){
    while(low<high){
        int p=Partition(A,low,high);
        if(p==k) return;
        if(p>k) high=p-1;
        else low=p+1;
    }
}

2020 年 41 题 · 三元组最小距离

D=|a-b|+|b-c|+|c-a|。三个非空升序整数数组各取一个元素，求所有三元组中的最小距离。按题给样例处理整数（含负数、零）。

#include <stdlib.h>
#include <stdio.h>
void MinDistance(int S1[],int S2[],int S3[],
                 int n1,int n2,int n3){
    int R[4]={abs(S1[0]-S2[0])+abs(S2[0]-S3[0])
              +abs(S3[0]-S1[0]),0,0,0};
    for(int i=0;i<n1;i++)
        for(int j=0;j<n2;j++)
            for(int k=0;k<n3;k++){
                int d=abs(S1[i]-S2[j])+abs(S2[j]-S3[k])
                     +abs(S3[k]-S1[i]);
                if(d<R[0]){
                    R[0]=d; R[1]=i; R[2]=j; R[3]=k;
                }
            }
    printf("%d",R[0]);
}

纠错：初始化最小距离及下标；for 的三个表达式用分号隔开；输出结果。若仅要求距离，可只维护一个 minD 变量，无需记录下标。

时间 O(n1·n2·n3)，等长时 O(n³)；辅助空间 O(1)。

2025 年 41 题 · 后缀最大乘积

对每个 i，求 A[i] 与 A[j] 的最大乘积，限制 i≤j<n，保存至 res[i]。

原始手写思路

外层枚举 i，内层从 i 开始扫描后缀。若 A[i]≥0，找后缀最大值；若 A[i]<0，找后缀最小值，然后相乘。

关键纠错：max/min 必须在每轮 i 开始时重置为 A[i]。例如 [8,3,2] 若不重置，后缀最大值会错误地一直保留 8。内层 j 从 i 开始（若已用 A[i] 初始化，也可从 i+1 开始）。

void CalMulMax(int A[],int res[],int n){
    for(int i=0;i<n;i++){
        int max=A[i], min=A[i];
        for(int j=i;j<n;j++){
            if(A[i]>=0 && A[j]>max) max=A[j];
            else if(A[i]<0 && A[j]<min) min=A[j];
        }
        if(A[i]>=0) res[i]=A[i]*max;
        else res[i]=A[i]*min;
    }
}

更容易手写的暴力版本：直接比较乘积

void CalMulMax(int A[],int res[],int n){
    for(int i=0;i<n;i++){
        res[i]=A[i]*A[i];
        for(int j=i+1;j<n;j++){
            int temp=A[i]*A[j];
            if(temp>res[i]) res[i]=temp;
        }
    }
}

两个版本均为时间 O(n²)，辅助空间 O(1)。无需排序，否则会改变原下标对应的后缀范围。

说明：代码沿用考试常见的整数计算不溢出假设。暴力版本保证枚举正确，但题目要求尽可能高效，可能扣效率分。
