连续子序列最大和：三层循环暴力解

2026-11-26 · 数据结构 · 数组枚举

问题

给定 A={1,-2,3,5}，res[i] 表示长度为 i+1 的连续子序列的最大元素和。求 res。

手工求解：固定长度 → 移动起点 → 逐项累加

结果：res={5,8,6,7}

逐步观察三层循环

循环边界

① len 从 1 到 n，决定框的长度。

② j 为起点，终点为 j+len-1。要求 j+len-1 ≤ n-1，因此 j ≤ n-len。

③ k 从 j 到 j+len-1，逐项累加，即 k < j+len。

C 语言代码（len 表示长度）

#include <stdio.h>
#include <limits.h>

void ans(int A[], int n)
{
    int res[n];
    for (int len = 1; len <= n; len++)
    {
        int max = INT_MIN;
        for (int j = 0; j <= n - len; j++)
        {
            int sum = 0;
            for (int k = j; k < j + len; k++)
                sum += A[k];

            if (sum > max)
                max = sum;
        }
        res[len - 1] = max;
    }
    for (int i = 0; i < n; i++)
        printf("%d ", res[i]);
}

时间复杂度 O(n³)，结果数组空间 O(n)。假设 n>0 且元素和不溢出 int。

易错点

max 在第一层内部初始化：每种长度重新寻找最大值；不能初始化为 0，因为可能全是负数。

sum 在第二层内部初始化：每移动一次框就重新求和。第三层结束后才比较 max；第二层结束后才保存 res[len-1]。
